# Waqtimer

ESP32-S3 desk clock with a ~4-inch color LCD, custom PCB (EasyEDA), custom 3D-printed
enclosure, and a React Native app that changes wallpapers over BLE.

## Status
| Area | State |
|---|---|
| Breadboard prototype | Not started |
| Schematic and PCB | Not started |
| Enclosure | Not started |
| App | Not started |

## Repo layout
- `hardware/`  EasyEDA project notes, exports (schematic PDF, gerbers, BOM), datasheets
- `firmware/`  ESP-IDF project
- `app/`       React Native app
- `enclosure/` CAD, STL files, renders
- `docs/`      Pin map, power notes, BLE protocol, decisions
- `content/`   Video scripts and shot lists
